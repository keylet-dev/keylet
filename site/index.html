Three platforms, one shared core

Zero-knowledge client crypto powered by Web Crypto, Argon2id, and Encrypt-then-MAC.

Browser Extension Chrome & Firefox

Command-palette popup built with React 19 and @ui-sdk/react.

  • Global search, Ctrl/Cmd+Shift+L autofill, inline dropdown & save prompt
  • Auto-fetched website favicons & automatic Light/Dark theme
  • Live 30s TOTP ring, password generator, Ed25519 SSH keygen & multi-account switch

CLI & SSH Agent @keylet/cli

Two-level CLI with a background Unix-socket daemon and auto-lock timer.

  • keylet:// URI & --from env injection via keylet run
  • In-memory Ed25519 SSH_AUTH_SOCK agent
  • table, json, yaml & --json-path outputs; 1Password .1pux, Bitwarden & Chrome import

Android App APK v0.1.0

Jetpack Compose app with Material 3 Light/Dark adaptive glass UI.

  • Biometric KeyStore quick unlock
  • System AutofillService integration
  • Multi-account management & full Vaultwarden 2026+ sync

Security by design

Your master password and decrypted symmetric keys never leave volatile memory in plaintext.

Encrypt-then-MAC

Verifies HMAC-SHA256 before AES-256-CBC decryption on every cipher, folder, and org key.

KDF & Protocol Parity

Supports both PBKDF2-SHA256 and Argon2id, plus Vaultwarden 2026+ encryptedFor payloads.

Zero Telemetry

No analytics, no third-party tracking, no remote code execution. Open source under MIT.
